# Vincent Wong — Portfolio

Bioinformatician & Computational Biologist portfolio. Single-page site with anime.js v4 animations and a three.js 3D model viewer.

## Tech Stack

- **anime.js v4** — scroll-triggered animations, stagger, timelines
- **three.js r164** — GLB model viewer with OrbitControls
- **Google Fonts** — Inter + JetBrains Mono
- Pure CSS with light/dark theme toggle

## 3D Model

Place `purple cell 3d model.glb` (neutrophil expelling NETs) in the project root. The viewer auto-rotates and supports drag/zoom.

## Deploy

GitHub Pages auto-deploys from the `main` branch.
